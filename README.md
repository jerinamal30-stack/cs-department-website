# Department of Computer Science – HTML Website

Assignment 2: Design and document a website for a college department using HTML.

## Files

| File | Purpose |
|------|---------|
| `index.html` | The complete multi-section website |
| `style.css` | Basic styling (colours, layout, table and form look) |
| `images/logo.svg` | Department logo used with the `<img>` tag |

## HTML concepts demonstrated

1. **Document structure** – `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`
2. **Headings, paragraphs, text formatting** – `<h1>`–`<h3>`, `<p>`, `<strong>`, `<em>`, `<mark>`, `<sub>`, `<sup>`, `<code>`
3. **Lists** – one unordered list of programmes and one ordered list of 7 subjects
4. **Hyperlinks** – external, internal (`#contact`) and `mailto:` links
5. **Images** – department logo with `<img>`
6. **Tables** – faculty table with 6 members (name, designation, specialization)
7. **Forms** – student enquiry form (name, email, phone, course preference, submit)
8. **Semantic HTML** – `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`

## How to run

Open `index.html` in any web browser. No installation is needed.

## Note

College name, faculty names and contact details are sample data. Replace them with your own department's real details.
